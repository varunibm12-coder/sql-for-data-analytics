# Day 09 - SQL JOINs

## 📌 Overview

On Day 9, I learned how to combine data from multiple tables using SQL JOINs in MySQL. JOINs are important for data analysts because real-world databases store information across multiple related tables.

I practiced different types of JOINs using employee and department datasets.

## 📚 Topics Covered

- INNER JOIN
- LEFT JOIN
- RIGHT JOIN
- SELF JOIN
- Table Aliases
- Joining tables using common columns
- Filtering joined data using WHERE
- Handling NULL values in JOIN results

## 💻 SQL Commands Practiced

- INNER JOIN – Retrieves matching records from both tables.
- LEFT JOIN – Retrieves all records from the left table and matching records from the right table.
- RIGHT JOIN – Retrieves all records from the right table and matching records from the left table.
- SELF JOIN – Joins a table with itself to retrieve related records.
- WHERE with JOIN – Filters joined records based on conditions.
- ORDER BY with JOIN – Sorts the joined results.
