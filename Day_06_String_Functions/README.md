## 📚 Key Learnings

- Converted text to uppercase using `UPPER()`.
- Converted text to lowercase using `LOWER()`.
- Calculated string length using `LENGTH()`.
- Combined multiple strings using `CONCAT()`.
- Extracted specific characters using `SUBSTRING()`.
- Retrieved characters from the left and right using `LEFT()` and `RIGHT()`.
- Removed unnecessary spaces using `TRIM()`, `LTRIM()`, and `RTRIM()`.
- Replaced text values using `REPLACE()`.
- Improved SQL string manipulation and data-cleaning skills through LeetCode practice.
