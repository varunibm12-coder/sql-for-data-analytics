# Day 04 - Aggregate Functions

## 📌 Overview

On Day 4, I learned how to summarize and analyze data using SQL Aggregate Functions. I practiced calculating totals, averages, minimum and maximum values, counting records, and applying aggregate functions with filtering conditions to generate meaningful insights from datasets.

---

## 🎯 Topics Covered

- COUNT()
- SUM()
- AVG()
- MIN()
- MAX()
- COUNT(DISTINCT)
- Aggregate Functions with WHERE

---

## 💻 SQL Concepts Practiced

- Counting total records using `COUNT()`
- Calculating totals using `SUM()`
- Finding average values using `AVG()`
- Retrieving minimum values using `MIN()`
- Retrieving maximum values using `MAX()`
- Counting unique values using `COUNT(DISTINCT)`
- Combining aggregate functions with the `WHERE` clause
