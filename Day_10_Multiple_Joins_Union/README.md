## 📌 Overview

On Day 10, I learned how to combine data from three or more tables using Multiple JOINs and combine results from multiple SELECT statements using UNION and UNION ALL in MySQL.

- Filtering Joined Data Using WHERE

## 💻 SQL Commands Practiced

- **Multiple JOINs:** Combines data from three or more related tables.
- **INNER JOIN:** Retrieves matching records from multiple tables.
- **LEFT JOIN:** Retrieves all records from the left table and matching records from the right table.
- **UNION:** Combines results from multiple SELECT statements and removes duplicates.
- **UNION ALL:** Combines results from multiple SELECT statements while keeping duplicates.
- **ORDER BY:** Sorts combined or joined results.
- **WHERE:** Filters records based on specific conditions.
