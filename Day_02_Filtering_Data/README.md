# Day 02 - Filtering Data

## 📌 Overview

On Day 2, I learned how to filter data from tables using SQL conditions. I practiced retrieving specific records based on comparison operators, logical operators, pattern matching, and NULL checks.

---

## 🎯 Topics Covered

- WHERE Clause
- Comparison Operators (=, >, <, >=, <=, <>)
- Logical Operators (AND, OR, NOT)
- BETWEEN
- IN
- NOT IN
- LIKE
- IS NULL
- IS NOT NULL

## 📚 Key Learnings

- Filtered rows using the `WHERE` clause.
- Applied comparison operators to retrieve specific records.
- Combined multiple conditions using `AND`, `OR`, and `NOT`.
- Filtered data using ranges with `BETWEEN`.
- Retrieved records using lists with `IN` and `NOT IN`.
- Performed pattern matching using `LIKE`.
- Identified missing values using `IS NULL` and `IS NOT NULL`.
- Strengthened filtering skills through LeetCode SQL practice.
